# NESCRATCH

A scratch NestJS application in TypeScript.

## About The Project

A minimal NestJS 7 application (`src/main.ts` bootstraps `AppModule` and listens on port 3000), run directly from TypeScript sources with `ts-node-dev`.

### Built With

- Node.js
- NestJS 7
- TypeScript (ts-node-dev)

## Getting Started

### Prerequisites

- Node.js

### Installation

```sh
npm install
npm start        # npx ts-node-dev src/main.ts (serves http://localhost:3000)
```
